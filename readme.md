# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Netflix 
- Contexto: Netflix recopila grandes cantidades de datos de sus usuarios para recomendar películas y series personalizadas y mejorar la experiencia del usuario.
## 2) Conceptos
- Big Data: Conjunto de datos masivos que no pueden ser gestionados con herramientas tradicionales debido a su gran volumen, velocidad y variedad.

- Análisis de datos: Proceso de examinar, limpiar y transformar los datos para obtener información útil que permita tomar decisiones.

- Machine Learning: Rama de la IA que permite a los sistemas aprender automáticamente a partir de los datos sin ser programados explícitamente.

- Deep Learning: Subcampo del Machine Learning que utiliza redes neuronales profundas para analizar datos complejos como imágenes, audio o patrones de comportamiento.

- IA: Conjunto de tecnologías que permiten a las máquinas simular inteligencia humana, como aprender, razonar y tomar decisiones.
